# 05 · 两宋词史与词人谱系

> **分期原则**：以**文体与政治的双重节律**分期——词的体式演进（令→慢→雅化→格律化）与王朝事件（靖康之变、开禧北伐、宋亡）同步。
> **生卒年**：凡标「约」者，学界有异说，**不可断为定年**。
> **作品归属**：本辑为「辑存」，词人首数以 `modules/01_songci-quanji.md` 为准，非全集。

## §三 词史的四次结构性转折

### 3.1 第一次：令词成立（唐五代）

- 由**敦煌曲子词**（民间、俚俗、实用）→ **花间集**（文人、精工、艳情）→ **南唐**（个人、真率、血泪）。
- 关键变化：词的**主体**从「歌者」转向「作者」，李煜是转折点。

### 3.2 第二次：慢词兴起（柳永）

- 令词（40—60 字）容量有限，只能写「一瞬」。
- 柳永用**长调 + 铺叙 + 领字**，使词可以写「一个过程」，词的时间长度由此扩张三倍。
- 代价：**俗**。李清照讥其「词语尘下」，正因他写给歌者听，不是写给士大夫看。

### 3.3 第三次：雅化与技艺化（周邦彦—姜夔—吴文英）

- 周邦彦：**章法**（回环、勾勒、时空折叠）+ **音律**（大晟府乐律）→ 词成为可精密施工的工艺品。
- 姜夔：**清空**——以虚写实，以冷色调替代浓艳，以自度曲摆脱旧调束缚。
- 吴文英：**密丽**——把时空叠印做到极致，代价是「七宝楼台」之讥。
- 这一路被后世称为**格律派 / 雅词派**，清代常州词派与晚清词学（朱祖谋、况周颐）皆奉为圭臬。

### 3.4 第四次：家国入词（靖康之变—宋亡）

- 南渡：李清照、张元干、岳飞——词开始承担**个人身世与国家命运**的双重叙事。
- 南宋中期：辛弃疾——**以文为词**，把经史议论塞进词里，词的「思想容量」达到极限。
- 宋末：周密、王沂孙、张炎、蒋捷、刘辰翁——**咏物寄托**与**词史**，词的「史笔」功能完成。

## §四 元明之衰与清词中兴（简述，本辑不收）

- 元：词乐失传，词变为「案头文学」，曲兴而词衰。
- 明：词坛摹拟《花间》《草堂》，**明人好以婉约豪放二分论词**，即出于此时（张綖）。
- 清：**词学中兴**。
  - 陈维崧（阳羡派）：豪放，学苏辛。
  - 朱彝尊（浙西派）：尊姜张，主清空醇雅。
  - 纳兰性德：自然真率，「北宋以来，一人而已」（王国维语，文献）。
  - 张惠言、周济（常州派）：以**比兴寄托**说词，词学理论化。
  - 晚清四大家（王鹏运、朱祖谋、郑文焯、况周颐）：校勘与词律之学大成。
- **王国维《人间词话》**（1908—1909）：以「境界」说收束千年词学，也开启了现代词学。
