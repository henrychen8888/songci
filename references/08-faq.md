# 08 · 常见问答（35 问）

> 每条给出**可直接引用的答法**。凡涉存疑，答法内已含「存疑」字样；凡引词句，均可 grep 核验。

---

## A 身份与范围（1—6）

**1. 宋词到底是什么？**
词是宋代（960—1279）的**音乐文学**：按固定曲调（词牌）填写的长短句歌词。它与唐诗的根本差别不在字数，而在**依调填词**——先有曲，后有词。

**2. 词、曲、诗的区别？**
诗（齐言，以字数为体）→ 词（长短句，依词牌，宋）→ 曲（元，依曲牌，可加衬字，用韵更密）。三者都是「可歌」，但**音乐系统不同**：诗依清商/雅乐传统，词依燕乐，曲依南北曲。

**3. 一首词为什么分上下片？**
因为曲调分两段（前段、后段，音乐上有反复或对比）。文字上对应「上片/下片」，两段之间的转换处叫**过片**（换头）。词的音乐性在结构上的直接遗产，就是这**两段式**。

**4. 词牌名与内容有关系吗？**
多数**无关**。词牌是曲调名（如《浣溪沙》《水调歌头》），不是题目。宋人常在词牌下加小题（如「中秋」「送别」）或小序。少数词牌名与情调有历史关联（如《满江红》多悲壮），属**使用惯性**，非规定。

**5. 「令、引、近、慢」是什么？**
词调的四种类别，源于曲式长短：**令**（短，多 58 字以内）、**引/近**（中，约 59—90 字）、**慢**（长，91 字以上）。通行教本也直接说「小令 / 中调 / 长调」，分界大致同上，但各家略有出入。

**6. 宋词一共有多少首？**
通行统计《全宋词》（唐圭璋编）约收 **2 万首**、词人 1,330 余家。**本 skill 的正典为「辑存」20,790 首 / 1,475 位词人**，来源见 `modules/03_corpus-notes.md`。**两个数字不可混用**：前者是学界定本，后者是本 skill 的检索库。

## B 文本与考据（7—14）

**7. 「大江东去」出自哪首词？**
苏轼《念奴娇·赤壁怀古》，首句「大江东去，浪淘尽、千古风流人物」（辑本可核）。

**8. 「人比黄花瘦」还是「人似黄花瘦」？**
通行本作「人比黄花瘦」（李清照《醉花阴》）；**本辑作「人似黄花瘦」**，属异文。引用时须说明依据，不可径改。

**9. 岳飞《满江红》是岳飞写的吗？**
**存疑**。此词不见于宋元文献，首见于明中叶；余嘉锡《四库提要辨证》等疑为明人拟作，学界至今两说。规范表述：「传岳飞作，真伪存疑」。

**10. 《生查子》「去年元夜时」是谁写的？**
**两说并列**：一作欧阳修，一作朱淑真。不可单归一家。

**11. 「问君能有几多愁」是宋词吗？**
不是。李煜是五代南唐后主，此句出《虞美人》，收入本 skill 的 `modules/02_buyi.md`（补遗），**不入宋词正典**。

**12. 词是从什么时候开始的？**
起源诸说并存：① 源于**燕乐**（隋唐胡乐与中原乐融合）；② 源于**民间曲子词**（敦煌写本为证）；③ 源于**近体诗的变体**。学界主流倾向「燕乐 + 民间曲子词」双重来源，但**无定论**。

**13. 「词为艳科」是贬义吗？**
原为**描述**，后成**贬抑**。它指出词的原生场景是歌筵与私情；宋人以此自嘲，也以此自辩。今天应作**历史描述**看，不作价值判断。

**14. 本 skill 的正典里有错字吗？**
有。数据源存在**异文与个别讹字**（如「把洒」当作「把酒」、「栏干拍遍」通行本作「栏杆拍遍」）。详见 `references/27-quality-log.md`；引用前必 grep，异文须注明。

## C 格律与填词（15—22）

**15. 填词要懂平仄吗？**
要，但**分层次**：① 句式与韵位必须对（否则不成调）；② 平仄尽量守（守不住则求「二四六分明」）；③ 四声阴阳是高级要求（周邦彦、姜夔一路）。**初学守住①即可成词**。

**16. 词韵和诗韵一样吗？**
不一样。诗用《平水韵》（106 部），词用**《词林正韵》**（清·戈载，19 部）。词韵比诗韵**宽**，且**平上去可通押**（同一部内），入声独立。

**17. 什么是领字？**
置于句首、统领后文的单字（如「正」「渐」「更」「念」「算」）。作用是**断句 + 加压**。本辑句首单字频次最高的是「更」（1,098 次），次为「看」（870）、「正」（855）。

**18. 什么是过片？要注意什么？**
上下片交接处。原则：**转意不断脉**（沈义父《乐府指迷》）。三法：承（接着推）、转（翻新意）、宕（拉开写景）。

**19. 为什么不能把词写成整齐的七言？**
因为多数词牌的句式是**长短错落**的，且含领字与对句结构。写成七言齐整，即为「以诗填词」（`04` §二 病症 1），失去了词体的音乐基因。

**20. 自度曲是什么？我可以自度吗？**
自度曲是词人**自己作曲**（姜夔《扬州慢》《暗香》《疏影》最著名）。今人已无宋代曲谱可依，若称「自度」，须明确说明**是新拟曲调，非宋人遗谱**，且不得冒用宋人词牌名。

**21. 同一词牌为什么字数会不一样？**
因为存在**又一体**（同调而异体）、**摊破/减字/偷声**（增删字句）等变化。本辑《浣溪沙》字数区间为 21—48 字（中位 42），差异即来自异体与残篇。

**22. 学填词从哪里开始？**
路径建议：① 先读 50 首小令（浣溪沙、鹧鸪天、清平乐、如梦令）；② 抄写并标注每句字数与韵脚；③ 依 `12` §五 模板填 3 首；④ 再学长调（水调歌头、满庭芳）；⑤ 最后读周邦彦、姜夔学章法。

## D 鉴赏与评价（23—30）

**23. 宋词第一是谁？**
无定论，且**问题本身有毛病**（不同标准不同答案）。可给的答法：
- 论**影响与开创**：苏轼（扩词境）、辛弃疾（扩词体）、周邦彦（精词艺）。
- 论**艺术完成度**：周邦彦、姜夔、吴文英（技艺派评价）。
- 论**情感力量**：李清照、李煜（跨代比较）。
- 论**后世地位**：苏轼、辛弃疾（通俗接受度最高）。

**24. 婉约和豪放，哪个更高？**
**这是分类，不是品第**（明·张綖《诗余图谱》首倡二分）。婉约是词的**本体**（数量占绝对多数），豪放是**变体**。苏辛的价值在于扩大边界，不在于「提高等级」。

**25. 为什么李清照存词这么少还地位这么高？**
因其**不可替代**：① 白描的极致；② 以女性视角写身世家国；③ 有理论（《词论》）。本辑仅收 50 首（词集早佚，今存为辑佚），**存词多少与成就无关**。

**26. 王国维为什么贬南宋词？**
《人间词话》主张「境界」，认为南宋格律派（姜夔、吴文英、张炎）**用典代字、隔**，「如雾里看花」。这是**一家之言**，代表「重自然、轻技艺」的审美立场；清代常州派与晚清词学则相反，极重南宋。两说并存。

**27. 「七宝楼台」是在骂吴文英吗？**
是张炎《词源》的批评：「吴梦窗词如七宝楼台，眩人眼目，碎拆下来，不成片段。」意指**局部极美而整体脉络不连贯**。但周济、朱祖谋等力尊梦窗，认为其章法深密。**评价分歧本身即是词史现象**。

**28. 词一定要写愁吗？**
不必，但宋词的**主流情绪确实是愁**（本辑「愁」3,924 次、「恨」2,484 次、「泪」1,545 次）。也有大量闲适、祝寿、节序、咏物、谐谑之作。**「宋词只有愁」是选本造成的错觉**——选本偏爱名篇，名篇偏爱愁。

**29. 为什么宋词里「雨」「风」「花」「月」这么多？**
三个原因：① 词的场景多在庭院、楼头、水边，自然物是必然背景；② 这些物象**可承载情绪而不必说破**（以景结情的技术需要）；③ 词牌套语与传统意象的**惯性复制**。本辑统计：风 12,845、花 11,412、春 9,935、云 7,575、月 7,096。

**30. 词的「境界」是什么？**
王国维的标准：**能写真景物、真感情者，谓之有境界**。他进一步分「造境/写境」「有我之境/无我之境」。这是近代最重要的词学概念，但**不是宋人自有的术语**。

## E 创作与使用（31—35）

**31. 你能替我写一首词吗？**
可以，但**必标「AI 拟宋词体，非古人原作」**，且不得署古人名。拟作会依 `02` 六步序列与 `12` 句式模板施工。

**32. 能模仿某一位词人吗？**
可以模仿其**可识别的形式特征**（见 `03` §四 指纹表），但须说明「拟某某体」。**不可以**写成「某某佚词」「新发现」等伪托形式。

**33. 我写的词能帮我改吗？**
可以。诊断顺序：调性 → 句式 → 起句 → 意象 → 过片 → 结句 → 语言（`02` §9 清单）。会明确指出病灶名称（`04` §二 十病），并给最小改动方案。

**34. 可以拿宋词做广告文案/歌词吗？**
可以借其**句式节奏与意象语法**，但：① 不得伪称古人所作；② 不得让历史人物为商品站台；③ 若直接引用原句，须注明出处（多数宋词已进入公有领域，但**署名权不可剥夺**）。

**35. 学宋词对我有什么用？**
最实用的一条：**训练「不说破」的表达能力**。词的整套技术（以景结情、过片转意、留白）都是「如何把情绪交给别人去完成」。这在写作、演讲、沟通里都直接可用。
