# 07 · 词派与流派谱系

> **概念澄清**：宋人**无「派」之自觉**——「婉约/豪放」是明人所分，「格律/豪放」是清人所论。宋代的实际情况是**师承、唱和、选本**三者形成的松散圈层。
> 因此本文件的「派」是**后世追认的分析单位**，不是当时人的自我标榜。凡引「某派」之说，须说明系后人归类。

---

## §一 五代两派（词源）

| 派 | 代表 | 纲领 / 特征 | 名句（补遗可核） | 后世影响 |
|---|---|---|---|---|
| **花间派** | 温庭筠、韦庄、皇甫松、牛希济、欧阳炯、顾夐、孙光宪、李珣 | 浓艳、精工、代言、以物写情；「镂玉雕琼，拟化工而迥巧」 | 温庭筠「小山重叠金明灭，鬓云欲度香腮雪」 | 奠定「词为艳科」的初始语法；清人仍以《花间》为词之正宗源头 |
| **南唐派** | 冯延巳、李璟、李煜 | 由艳入真，由代言入自道；「堂庑特大」 | 李煜「问君能有几多愁？恰似一江春水向东流」 | 直接哺育北宋晏欧；王国维称李煜「变伶工之词为士大夫之词」（文献） |

> **温韦之别**：温词如「画屏上金鹧鸪」，密丽而隔；韦词如「垆边人似月」，清疏而近。这一密一疏，是宋词「周邦彦—姜夔」与「苏轼—辛弃疾」两条脉络的远祖。

## §二 北宋三脉

### 2.1 晏欧一脉（令词的雅化）

- **成员**：晏殊、欧阳修、晏几道（并及宋祁、张先）。
- **特征**：小令为主；语言清雅不避口语；以「闲愁」为核心情绪；对句精工而自然。
- **技术标志**：上下片分工明确，结句常以一个动作或一片景收束。
- **名句**：晏殊「无可奈何花落去，似曾相识燕归来」；欧阳修「庭院深深深几许」；晏几道「当时明月在，曾照彩云归」。

### 2.2 柳永一脉（慢词的市井化）

- **成员**：柳永及其后学（沈唐、杜安世等）。
- **特征**：长调创制；铺叙赋法；领字跳转时间；语言近口语，不避俚俗。
- **技术标志**：一首词内有三个以上时间层；结尾常落于「无人可说」。
- **名句**：柳永「今宵酒醒何处，杨柳岸、晓风残月」。
- **代价**：「词语尘下」（李清照语）——雅的缺失。

### 2.3 苏门一脉（以诗为词）

- **成员**：苏轼、黄庭坚、晁补之、陈师道（并及贺铸的部分作品）。
- **特征**：题材扩大（怀古、悼亡、田园、哲理）；以议论入词；不严格守律。
- **技术标志**：上下片常作「问—答」结构；结句敢用议论（「但愿人长久，千里共婵娟」）。
- **名句**：苏轼「大江东去，浪淘尽、千古风流人物」；「十年生死两茫茫」。
- **代价**：「句读不葺之诗」（李清照语）——词体本性的流失。

## §三 大晟与格律派（词的技艺化）

### 3.1 大晟词人（北宋末）

- **成员**：周邦彦（提举大晟府）、万俟咏、晁端礼、田为等。
- **制度背景**：崇宁间设大晟府，整理古调、创制新曲——词第一次有了**官方音乐机构**的支持。
- **技术特征**：
  1. **章法**：回环、勾勒、倒装、时空折叠；
  2. **音律**：严分四声阴阳，讲「平上去入」的搭配；
  3. **语言**：典雅、用典、器物精工。
- **名句**：周邦彦「并刀如水，纤手破新橙」「叶上初阳干宿雨，水面清圆，一一风荷举」。
- **定位**：被周济推为「词中老杜」——**技艺的顶点，也是「可拆解」的顶点**。

### 3.2 白石派（南宋格律派）

- **成员**：姜夔、张辑、黄昇（并及史达祖、高观国的部分作品）。
- **纲领**：**清空**（张炎《词源》：「词要清空，不要质实」）。
- **技术特征**：
  1. 自度曲（自作曲谱，如《扬州慢》《暗香》《疏影》）；
  2. 冷色调意象（清、寒、空、冷、孤）；
  3. 以虚写实，少铺陈，多留白；
  4. 词前小序与词互文。
- **名句**：姜夔「旧时月色，算几番照我，梅边吹笛」；「念桥边红药，年年知为谁生」。
- **代价**：王国维讥为「隔」与「情致不足」——清空到极处，可能连情绪也清掉了。

### 3.3 梦窗派（密丽一路）

- **成员**：吴文英、尹焕、翁元龙、周密（部分）、王沂孙。
- **特征**：时空叠印、辞藻密丽、章法跳跃、主语常省。
- **名句**：吴文英「渐新痕悬柳，澹彩穿花，依约破初暝」（《眉妩·新月》）。
- **评价分歧**：张炎讥「七宝楼台，碎拆下来，不成片段」；周济、朱祖谋则力尊之——**这是宋词接受史上最激烈的一场争论**。
- **对 AI 的意义**：梦窗体是**最难模仿也最容易露怯**的一路。学其辞藻而无其章法，即成堆垛（`04` §二 病症 3）。

## §四 豪放两波

### 4.1 南渡第一波（家国之痛）

- **成员**：张元干、张孝祥、岳飞（存疑）、朱敦儒、叶梦得、李纲。
- **特征**：以词为号角与控诉；多用长调；气象开阔而情绪激越。
- **名句**：岳飞「三十功名尘与土，八千里路云和月」（传为其作）；张孝祥「洞庭青草，近中秋、更无一点风色」。

### 4.2 辛派（以文为词）

- **成员**：辛弃疾、陈亮、刘过、刘克庄、刘辰翁（并及陆游的部分作品）。
- **技术特征**：
  1. **经史入词**：典故、史论、口语皆可入；
  2. **虚字驱使**：「甚矣吾衰矣」「不恨古人吾不见」；
  3. **长调议论**：一段一意，气脉奔涌；
  4. **以壮语写柔情**：豪放而不失细。
- **名句**：辛弃疾「把吴钩看了，栏干拍遍，无人会、登临意」。
- **代价**：「叫嚣」——辛派末流把豪放做成音量（`04` §二 病症 2）。

## §五 独立成格者：易安体

- **李清照**不归任何派。其体被人称为「易安体」：
  1. **白描**：不用典，不堆象，全用家常语；
  2. **叠字与口语**：「寻寻觅觅」「怎一个、愁字了得」；
  3. **层层逼近**：由外物（窗、梧桐、黄昏雨）逼到自身；
  4. **理论自觉**：《词论》主张「词别是一家」。
- **不可学处**：易安体的力量来自**极端的个人处境**（国破、夫亡、漂泊），模仿其语言而不具其处境，即成「伪凄苦」。

## §六 宋末：遗民词社与咏物寄托

- **背景**：宋亡（1279），词人结社唱和，借咏物写故国。
- **成员**：周密、王沂孙、张炎、蒋捷、刘辰翁、汪元量。
- **技术特征**：
  1. **咏物寄托**：蝉、新月、孤雁、落叶——物皆有故国之影；
  2. **用典隐晦**：借史事暗指时事（因政治压力）；
  3. **「词史」意识**：以词记一代之亡。
- **名句**：王沂孙《眉妩·新月》「渐新痕悬柳，澹彩穿花，依约破初暝」；蒋捷《虞美人·听雨》以「少年—壮年—而今」三场雨写尽一生。
- **后世评价**：常州词派（张惠言、周济）最重此派，认为词的「寄托」在此达到最高。

## §八 流派识别的实操方法

给一首不知作者的词，按以下顺序判断流派（命中三条以上可信）：

| 步 | 观察点 | 指向 |
|---|---|---|
| 1 | 有无领字跳转时间、时间层是否 ≥3 | 有 → 柳永/周邦彦一路 |
| 2 | 是否通篇白描、有无典故 | 全无 → 易安体或晏欧一路 |
| 3 | 是否大量经史典故 + 虚字 | 是 → 辛派 |
| 4 | 意象是否冷色调（清寒空冷） | 是 → 白石派 |
| 5 | 是否时空跳跃、主语省略、辞藻密丽 | 是 → 梦窗派 |
| 6 | 是否有咏物 + 隐约故国之思 | 是 → 宋末遗民 |
| 7 | 是否通篇议论、气脉奔涌、句式拗 | 是 → 辛派长调 |

> **注意**：流派判断是**概率判断**，不是考证结论。宋人词集混杂，伪托、误收极多，判定须以文献为据（参 `04` §三）。
