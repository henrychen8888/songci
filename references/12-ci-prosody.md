# 12 · 词律与填词技术

> **本文件的定位**：不是《钦定词谱》的替代品，而是**可操作的填词工程手册**。
> **数据说明**：§五 的「韵段句式模板」全部由 `scripts/stats.py` 从正典 20,790 首实时统计，取该调**最常见模板**及其覆盖篇数。它反映宋人的**实际写法**，不是格律书的规定谱。
> **重要区分**：**韵段 ≠ 句**。词集多以「韵段」（一韵到底的一段）为单位断行，一个韵段内可含数个句读。本文件的模板按**韵段字数**统计。

---

## §一 词调常识

### 1.1 词调的三个来源

| 来源 | 说明 | 例 |
|---|---|---|
| 教坊曲 / 燕乐旧曲 | 唐代教坊所存曲调，宋人沿用 | 《菩萨蛮》《浣溪沙》《临江仙》 |
| 民间曲子 | 市井传唱，后经文人雅化 | 《竹枝》《采莲》一路 |
| 自度曲 | 词人自作曲谱 | 姜夔《扬州慢》《暗香》《疏影》《长亭怨慢》 |

### 1.2 令 · 引 · 近 · 慢

| 类 | 字数（通行分法） | 特征 | 例 |
|---|---|---|---|
| 令 | 约 58 字以内 | 篇幅短，一瞬定格，多不换韵 | 如梦令（33）、浣溪沙（42）、清平乐（46） |
| 引 / 近 | 约 59—90 字 | 中篇，常有铺叙余地 | 临江仙（60）、蝶恋花（60）、江城子（70） |
| 慢 | 91 字以上 | 长调，多重时空推进，领字多 | 水调歌头（95）、念奴娇（100）、贺新郎（116）、沁园春（114） |

> 通行教本另用「小令 / 中调 / 长调」三分，界线与此大致相当（58 / 90 字），各书略有出入，**不必强分**。

### 1.3 变体术语

| 术语 | 含义 |
|---|---|
| **又一体** | 同名词牌而句读、字数不同（如《满江红》有平韵、仄韵两体） |
| **摊破** | 在原调基础上增添乐句、拆破句式（如《摊破浣溪沙》） |
| **减字 / 偷声** | 减少字句 / 增减音节点（如《减字木兰花》） |
| **促拍** | 加快节拍，字句加密 |
| **犯调** | 一曲之中转用他调（如《花犯》《凄凉犯》） |
| **转调** | 移调或改换宫调 |

## §二 句式：韵段与句读

- **韵段**：以押韵为界的一段。词集断行多按韵段。
- **句读**：韵段内部按语义与音乐停顿切分，用「、」标顿（半逗）。
- **例**：《雨霖铃》首韵段「寒蝉凄切」4 字；「对长亭晚，骤雨初歇」为一韵段 9 字，内含 3+6 两个句读。

> **填词时的实际做法**：先照 §五 模板把**每个韵段的字数**定死，再在韵段内部按语义安排顿逗。这比死记平仄谱更可行，也是宋人「倚声」的实际操作方式。

## §三 四声与平仄

### 3.1 四声

| 声 | 说明 | 词中地位 |
|---|---|---|
| 平 | 平声（含阴平、阳平） | 最宽，可通押 |
| 上 | 上声 | 与去声同属仄，但**上、去不可随意互换**（严处须辨） |
| 去 | 去声 | 去声字常作「领字」与「结句」的着力点 |
| 入 | 入声 | **独立一类**，不与平上去通押；宋代实际语音已开始消失，词中仍严守 |

### 3.2 平仄守则（分层执行）

| 层 | 要求 | 适用 |
|---|---|---|
| L1 | **韵段字数与韵位必须对** | 一切填词，不可省 |
| L2 | 句内平仄「二四六分明」，一三五可通融 | 常规 |
| L3 | 严守四声，辨上、去、入 | 周邦彦、姜夔、吴文英一路（格律派） |
| L4 | 辨五音阴阳（唇齿喉舌牙、清浊） | 仅李清照《词论》所要求的极致标准 |

> **给 AI 拟作的建议**：做到 **L1 + L2** 即可成词；L3 用于「拟格律派」时；L4 现代已无法真正还原，**不得声称做到**。

### 3.3 领字的声调规律

领字多用**去声**（「正」「渐」「更」「又」「但」「便」「纵」「任」「算」「料」「怕」）——去声有力，能「提起」后文。少数用上声（「想」「使」）。**平声极少作领字**，因平声无力。

## §四 韵：词林正韵十九部

> **填词用韵的四条硬规则**：
> 1. 同一首词内，**同一部内可通押**（如「风/空/中」同部），**不可跨部**（除有意换韵）。
> 2. **平韵调**（如《浣溪沙》）全篇押平声；**仄韵调**（如《满江红》《念奴娇》）全篇押仄声，且**上去可通、入声独立**。
> 3. **换韵调**（如《菩萨蛮》四换韵）须按调换，不可随意。
> 4. **韵字不可重复**（除有意叠韵，如「知否，知否」）。

## §六 拟作模板 A—F（按情绪选调）

| 模板 | 适合 | 词牌建议 | 结构配比 |
|---|---|---|---|
| **A 伤春** | 季节之悲、身世之感 | 浣溪沙 / 蝶恋花 / 清平乐 | 上片景（2 段）＋下片情（2 段）＋动作结 |
| **B 怀人** | 相思、忆旧、悼亡 | 鹧鸪天 / 临江仙 / 江城子 | 上片今（实写）＋下片昔（回忆）＋回到今 |
| **C 送别** | 离别、羁旅 | 雨霖铃（长调）/ 卜算子（小令） | 现场 → 想象前路 → 回望 → 无人可诉 |
| **D 怀古** | 登临、史感 | 念奴娇 / 水调歌头 / 满江红 | 眼前景 → 昔年事 → 今昔对照 → 以景结 |
| **E 咏物** | 寄托、托物 | 水龙吟 / 齐天乐 / 暗香 | 上片写物形，下片写物神，末句人物合一 |
| **F 闲适** | 隐逸、闲居 | 鹧鸪天 / 清平乐 / 好事近 | 日常细事 → 一点自嘲 → 一个动作收 |

**每模板的三条硬要求**：

1. 全篇只写**一件事**（不可 A 加 B）；
2. 过片必须有**转**（承/转/宕，见 `02` §5）；
3. 结句**不说破**（景结或问结）。

## §七 填词工序（可直接执行）

```
① 定情绪 → 选模板（§六 A–F）→ 定词牌（查 §五 字数与用韵）
② 选韵部（§四）→ 列出 5–8 个同部韵字备用
③ 按模板写各韵段，先保证字数，再调语序
④ 安排顿逗（「、」处可断可连）
⑤ 检查：韵脚是否同部、有无重韵、平韵调是否混入仄韵
⑥ 检查过片是否转意、结句是否说破
⑦ 朗读一遍（词的节奏感靠朗读校验，不靠眼睛）
```

## §八 自检表

| # | 项 | 通过标准 |
|---|---|---|
| 1 | 字数 | 各韵段字数符合模板（±0） |
| 2 | 韵部 | 全篇同部；换韵调按调换 |
| 3 | 韵字 | 不重复（有意叠韵除外） |
| 4 | 平仄 | 二四六分明 |
| 5 | 领字 | 去声领字用于长段起处 |
| 6 | 过片 | 有转意 |
| 7 | 结句 | 景结或问结 |
| 8 | 朗读 | 不拗口、不堆砌 |

> **能力的诚实边界**：本 skill 能保证**句式与韵部的合规**，**不能保证**「唱得准」——宋代燕乐曲谱绝大部分已失传，今人所谓「按谱填词」实为按**字句谱**（平仄句式），不是按音乐。凡涉「可歌」的表述，须说明这一点。
