# 宋词 · 文学家思维 skill（songci）

> 「无可奈何花落去，似曾相识燕归来。」——晏殊《浣溪沙》

## 简介

本 skill 把**两宋词（960—1279）**的词学观、意象系统、格律技术与声口，蒸馏为可被 AI 调用的「文学家思维技能」，架构与 `libai`（李白）同源——即「**文学家 14 维框架**」：正典语料 + 12 维分析 + 名篇赏析库 + 可执行脚本。

与 `libai` 的差别在于**对象不同**：`libai` 蒸馏**一位诗人**，本 skill 蒸馏**一个文体与一个朝代**（两宋词坛、27 位核心词人、九大流派）。因此它不扮演某位词人，而是作为**词体的守门人**：懂格律、辨流派、能赏析、能填词、且守得住真伪与异文的边界。

## 技能定位

- **领域**：宋代文学 · 词（鉴赏 / 词史 / 词律 / 考据 / 拟作）
- **核心框架**：**调 → 境 → 象 → 铺 → 转 → 响**（六步填词法）
- **正典**：两宋词 **20,790 首 / 1,475 词人 / 1,416 词牌 / 1,410,332 汉字**
- **补遗**：五代词源 **492 首**（花间集 447 + 南唐二主 45）
- **用途**：宋词鉴赏、词学普及、填词教学、AI 拟古写作示范

## 使用方法

1. 提到宋词 / 词牌 / 婉约 / 豪放 / 填词 / 某宋词人 → 自动激活
2. 按 `SKILL.md`「素材检索规则」定位维度文件，按需加载
3. 引词前先在 `modules/01`（或 `02`）检索；未命中标「本辑未收」
4. 拟作必须声明「AI 拟宋词体，非宋人原作」，并保证句式合调（`12` §五）

## 使用示例（摘要）

- **鉴赏**：问「《声声慢》好在哪里」→ 以「声音结构情绪」切入，十四叠字三层递进，附可核句
- **考据**：问「『人比黄花瘦』原文是这样吗」→ 说明本辑作「人似黄花瘦」，属异文；并提示「把洒」为讹字
- **词律**：问「《浣溪沙》怎么填」→ 给 42 字 / 5 韵段 / 模板 7-7-7-14-7 / 平韵 / 词林正韵某部
- **拟作**：问「写一首秋夜思乡的词」→ 择调（如《鹧鸪天》）→ 依模板填 → 附「AI 拟宋词体」声明
- **边界**：问「岳飞《满江红》是岳飞写的吗」→ 「传岳飞作，真伪存疑（不见宋元文献，首见于明中叶）」

## ⚠️ 素材边界

- 本辑为**辑存本**（20,790 首），非《全宋词》定本（约 2 万首 / 1,330 余家），**无校记**，学术引用须回查原书。
- **名篇齐备**：抽检 68 首常见名篇 68 首在辑内（异体字处需换字检索）。
- 已知缺陷：个别讹字、异文多、少量疑收元明词、归属未考订——逐条见 `references/27-quality-log.md`。
- 补遗不含冯延巳《阳春集》、温庭筠别集、敦煌曲子词；**未收 ≠ 无此作**。
- 宋词曲谱绝大部分失传，今人填词是按**字句谱**，不是按音乐；**不得声称「按古谱可歌」**。
