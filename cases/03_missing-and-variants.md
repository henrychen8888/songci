# 未收篇目与异文要点

> 本文件是 `references/26-corpus-inventory.md`（盘点）与 `references/27-quality-log.md`（校勘日志）的**速查摘要**，供回答「这首词为什么查不到 / 原文是不是这样」一类问题时直接使用。

---

## §一 本辑未收（可能是用户最常问到的）

| 篇目 / 内容 | 情况 | 怎么答 |
|---|---|---|
| 冯延巳《阳春集》全部 | 五代，正典（宋词）与补遗（花间集、南唐二主）**均未收** | 「本 skill 未收，属数据源范围限制，非无此作」 |
| 温庭筠别集、敦煌曲子词 | 同上 | 同上 |
| 花间集第 10 卷 | 数据源文件缺失，补遗收 9 卷 447 首 | 「补遗收 447 首，第 10 卷缺」 |
| 欧阳修《蝶恋花》「庭院深深深几许」全篇 | **本辑未收**（李清照《临江仙》借其句，此篇在辑内） | 只引李清照《临江仙》，或说明「欧公原篇本辑未收」 |
| 词话、词序、词集序跋 | 本辑只收词作 | 「属文献，非词作，不在正典」 |
| 残句 256 条 | 清洗时剔除（汉字 < 8） | 「本辑不收残句」 |

**铁律**：以上一律表述为「**本辑未收 / 待考**」，**绝不**写成「此人无此作」或「此为伪托」。

## §二 常被问到的异文（回答时按此标注）

| 名句 | 通行本 | 本辑 | 备注 |
|---|---|---|---|
| 李清照《醉花阴》 | 莫道不**销**魂…人**比**黄花瘦 | 莫道不**消**魂…人**似**黄花瘦 | 两处异文 |
| 李清照《醉花阴》 | 东篱把**酒** | 东篱把**洒** | **讹字**（勿照抄） |
| 晏几道《鹧鸪天》 | 歌尽桃花**扇底风** | 歌尽桃花**扇影风** | 异文 |
| 秦观《鹊桥仙》 | 两情若是**久长**时 | 两情若是**长久**时 | 词序异 |
| 辛弃疾《水龙吟》 | **栏杆**拍遍 | **栏干**拍遍 | 系统异体（阑/栏/干） |
| 岳飞《满江红》 | **凭栏**处 | **凭阑**处 | 系统异体 |
| 周邦彦《苏幕遮》 | **燎沉**香 | **燎沈**香 | 系统异体（沈/沉） |
| 王沂孙《齐天乐》 | 一襟**余**恨 | 一襟**馀**恨 | 系统异体（馀/余） |
| 张先「三影」 | 帘**压**卷花影／堕风絮无影 | 仅存「帘**押**残花影」；另两句未收 | 不可据本辑引全 |
| 李璟《摊破浣溪沙》（补遗） | 多少泪珠**何限**恨，倚**阑干** | **无限**恨，倚**栏杆** | 补遗异文 |
| 欧阳修《生查子》 | **月上**柳梢头…泪**湿**春衫袖 | **月到**柳梢头…泪**满**春衫袖 | 两处异文 |

**统一答法**：「本辑（辑存本）作 X，通行本作 Y；两者皆有所本，引用时以所标版本为准。」

## §三 名篇可用性结论

- **68 首常见名篇，68 首均在辑内**（抽检，见 `references/26` §四）。
- 唯二需要换字检索的是异体字：**燎沈香**（非沉香）、**一襟馀恨**（非余恨）。
- **结论**：本辑的短板不是「缺名篇」，而是**无校记、版本杂糅**。
