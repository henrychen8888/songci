# 语料说明 · 正典与补遗的来源、口径与缺陷

> **本文件的用途**：让任何人拿到这个 skill，都能判断「它凭什么这么说」。凡引用本 skill 的词句，其可靠性底线在此定义。

---

## §一 正典（`01_songci-quanji.md`）

| 项 | 内容 |
|---|---|
| 名称 | 宋词正典 · 两宋词辑存 |
| 规模 | **20,790 首 / 1,475 位词人 / 1,416 个词牌 / 1,410,332 汉字**（可复现） |
| 数据源 | chinese-poetry 开源项目「宋词」数据集（`ci.song.*.json` 共 22 个分卷，原始 21,050 条） |
| 文字 | 简体（zhconv 1.4.1，`zh-cn`） |
| 处理 | 繁→简 → 空白归一 → 去重（同作者+同词牌+同正文）→ 剔残句（汉字 < 8）→ 按词史序分组 → 逐韵段成行 |
| 清洗账目 | 原始 21,050 → 去重 −4 → 剔残句 −256 → **收录 20,790** |
| 文件规格 | 约 205,000 行 / 7.1 MB |

### 1.1 为什么不是《全宋词》

- 《全宋词》（唐圭璋编，中华书局）是**学界定本**，收词约 2 万首、词人 1,330 余家，有完整校记与出处。
- 本辑是**开源数据集整理本**，**无校记、无出处、无版本对校**，词人 1,475 家（多于《全宋词》，因含「无名氏」及部分疑收篇目）。
- **结论**：本辑可作**检索与统计的底本**，不可作**校勘与征引的定本**。正式学术引用须回查《全宋词》原书。

### 1.2 结构与检索约定

```
## 词人（N 首）          ← 词人分组（按词史序）
### 词牌·首句            ← 单篇（首句截取 9 字）
　　韵段一。              ← 正文：每韵段一行，全角空格缩进
　　韵段二。
```

- **一个韵段一行**（不是一句一行）。一个韵段内可含数个句读。
- 跨韵段引文在检索时须**分段查找**，不可整段匹配。
- 检索示例：`grep -n "大江东去" modules/01_songci-quanji.md`

## §二 补遗（`02_buyi.md`）

| 项 | 内容 |
|---|---|
| 名称 | 词源补遗 · 花间集与南唐二主词 |
| 规模 | **492 首**（花间集 447 首 / 17 家；南唐二主词 45 首，李煜 41、李璟 4） |
| 数据源 | chinese-poetry「五代诗词」（`huajianji-*.json`、`nantang/poetrys.json`） |
| 性质 | **五代词，非宋词，不入正典** |
| 缺陷 | 花间集部分篇目有**讹字**（数据源 OCR 遗留，如「时时微雨洗劫风光」当作「洗风光」）；南唐部分较可靠 |
| 用法 | 仅作**词源示例与风格参照**；引用须标「补遗」，且须与通行本对校 |

**未收**：冯延巳《阳春集》、温庭筠别集、敦煌曲子词。**未收 ≠ 无此作**。

## §三 三条铁律

### 3.1 引用前必 grep

任何词句写进答案之前，先在正典（或补遗）中检索命中。核验工具：

```bash
python scripts/verify_quotes.py \
  --corpus modules/01_songci-quanji.md \
  --buyi modules/02_buyi.md \
  --whitelist references/_quote-whitelist.txt \
  --docs SKILL.md "references/*.md" "cases/*.md"
```

### 3.2 异文必须注明

本辑**版本杂糅**，同一名句常有异文（详见 `references/27-quality-log.md`）。凡引用与通行本不同者，须写「**本辑作 X，通行本作 Y**」。

### 3.3 未收不可反推

本辑未收的篇目，只能表述为「**本辑未收 / 待考**」，绝不可写成「此人无此作」「此为伪托」。

## §四 已知缺陷（诚实清单）

| # | 缺陷 | 影响 | 缓解 |
|---|---|---|---|
| 1 | 无校记、无出处 | 不能作学术征引 | 标注「辑存本」，重要引用回查《全宋词》 |
| 2 | 版本杂糅，异文多 | 同一句有多种写法 | 引时注明「本辑作…」；`27` 记录关键异文 |
| 3 | 个别讹字（如「把洒」） | 逐字引用可能出错 | `27` 列出已发现者；存疑处改引他句 |
| 4 | 词人归属未考订 | 如《生查子》欧/朱之争 | 存疑者两说并列（`04` §三） |
| 5 | 疑收元明词 | 少量篇目可能非宋 | 不作时代判断，只作文学分析 |
| 6 | 残句剔除 256 条 | 部分断句不存 | 不影响名篇；残句不在正典 |
| 7 | 「无名氏」1,379 首 | 占比 6.6%，作者不明 | 引用时标「无名氏」 |
| 8 | 词牌名有合称（如「木兰花・玉楼春」） | 词牌统计会重复计 | 统计词牌数时按字符串计，已声明 |

## §五 统计口径（重要）

| 口径 | 说明 |
|---|---|
| 字频 | 全文子串计数（含标题、含套语复用）；**只作相对序位证据** |
| 篇数 | 按 `### 词牌·首句` 计；同一词牌异体不合并 |
| 词人数 | 按 `## 词人（N 首）` 计；「无名氏」计为一家 |
| 句式模板 | 按**韵段**字数统计，取该调最常见序列及其覆盖篇数 |
| 字数中位 | 该调所有篇目总字数的中位数（受残篇拉低区间下限） |

**禁止的推论**：

- ❌ 「宋词一共 20,790 首」（本辑是辑存，不是全集）
- ❌ 「李清照只有 50 首词」（是**本辑收 50 首**，非其存世总数）
- ❌ 「宋词最爱写风」（只能说「本辑中『风』字出现 12,845 次，居首」）
- ❌ 用字数反推「某调共 X 首」（如「浣溪沙 42 字故有 774 首」——因果倒置）

## §六 数据可复现性

| 文件 | 作用 |
|---|---|
| `scripts/build_corpus.py` | 从原始 JSON 重建正典（含清洗账目） |
